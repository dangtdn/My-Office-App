# My Office: releases

Downloads of the My Office desktop app for macOS.

Get the newest `.dmg` from [Releases](https://github.com/dangtdn/My-Office-App/releases/latest), open it and drag My Office to Applications.

From 0.3.0 on, the app checks this page for a newer release and shows an **Update** button on its top bar; one click (and a confirming click) downloads the update and restarts the app.
